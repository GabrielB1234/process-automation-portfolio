## Evidence model

The professional case studies answer:

- what kind of problem existed;
- what I designed or built;
- what technical patterns were used;
- what controls remained with people;
- what general outcome was achieved.

The `projects/` folder complements these descriptions with independently written synthetic implementations that can be inspected without relying on any production environment.
