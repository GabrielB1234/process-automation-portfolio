# Template & Data Preparation Automation

## Problem

A recurring spreadsheet-based workflow required data to be copied, reorganized, formatted, and placed into a standardized operational template.

The work was deterministic but repetitive, which increased handling time and created opportunities for copy/paste and formatting errors.

## What I built

I developed an Excel/VBA workflow that automated the repeatable preparation steps while preserving the analyst review point before downstream use.

The automation focused on:

- reading structured source data;
- moving information into a standardized output layout;
- applying consistent placement and formatting logic;
- reducing repeated copy/paste activity;
- leaving the generated output ready for human review.

## Stack

- Microsoft Excel
- VBA / Macros
- worksheet formulas and structured templates

## Controls

The automation prepared the output. It did not approve or execute financial activity independently.

Human review remained required before the resulting file could be used downstream.

## Outcome

The project materially reduced repetitive preparation effort and improved consistency in a recurring operational workflow.

## What this demonstrates

This is one of the earlier examples in my automation progression: understand the process, isolate deterministic steps, automate the repetition, and preserve the control points that require judgment.
