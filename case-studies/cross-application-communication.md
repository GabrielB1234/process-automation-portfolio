# Cross-Application Communication Workflow

## Problem

A recurring operational workflow required structured spreadsheet data to be transformed into formatted email communication.

Preparing the messages manually meant repeatedly selecting records, copying values, rebuilding tables, and checking that the final email matched the source data.

## What I built

I created an Excel/VBA workflow that connected spreadsheet data with Outlook and prepared the communication automatically.

The automation handled tasks such as:

- reading structured rows from Excel;
- selecting the relevant records for a communication;
- combining fixed text with variable operational data;
- preserving table-style formatting;
- creating the Outlook message for review.

## Stack

- Microsoft Excel
- VBA / Macros
- Microsoft Outlook automation
- HTML-formatted email generation

## Controls

The tool prepared the message but deliberately left the final recipient review and sending action with the user.

## Outcome

The workflow reduced repetitive communication-preparation work and improved consistency between spreadsheet data and the resulting message.

## What this demonstrates

This project moved beyond a single-workbook macro and into cross-application workflow automation: structured input, transformation logic, formatted output, and a clear human control point.

No original email templates, recipient information, production data, employer code, or internal business rules are published here.
